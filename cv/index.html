Research Experience

Protein Language Model-Based Signal Peptide Prediction

MSc Bioinformatics Project — Independently Implemented · Apr 2026

Built an end-to-end eukaryotic signal-peptide prediction pipeline using high-confidence UniProtKB/Swiss-Prot annotations and MMseqs2-based redundancy reduction. Compared von Heijne PSWM, biochemical-feature SVM, CNN-BiLSTM, and ESM-2 embedding-based models, achieving F1 = 0.962 and MCC = 0.957 on a held-out benchmark with the ESM-2-based model. Also analyzed amino-acid composition, signal-peptide lengths, kingdom-specific bias, and cleavage-site motifs for biological interpretation. Code

Protein Domain and Functional Annotation Using HMMER and MMseqs2

Feb – Mar 2026

Built a protein-domain annotation workflow using profile HMMs, HMMER, and MMseqs2 for large-scale sequence classification. Compared profile-based and sequence-similarity-based workflows, achieving MCC = 0.997 and MCC = 0.991, respectively, and connected classical homology methods to remote homology detection and protein-family classification. Code

Computational Epigenomics Analysis of DNA Methylation (Illumina 450K)

Jun – Jul 2025

Conducted an R/Bioconductor workflow for Illumina 450K methylation analysis, including quality control, normalization, PCA-based batch-effect assessment, differential methylation analysis, and DMR identification. Code

Chest X-Ray Pneumonia Detection via Transfer Learning

Apr – May 2026

Compared ResNet50, EfficientNetB0, and DenseNet-121 XRV under class imbalance, evaluating threshold selection, ensembling, test-time augmentation, and Grad-CAM interpretability. DenseNet-121 XRV performed best under the maximum-MCC strategy. Code
